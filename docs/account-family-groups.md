# 账号家庭组

家庭组用于记录账号归属：一个账号最多属于一个家庭组，多个账号填写相同名称即可归入同一家庭组。它与原有的调度/计费分组独立，不改变路由、额度、计费或平台权限，也不会向上游平台发送加入家庭的请求。

## 使用

- 新增、编辑账号：填写「家庭组」，可从输入建议选择已有名称，也可输入新名称。
- 批量加入/移动：选中账号 → 批量编辑 → 勾选「设置家庭组」→ 填写名称并保存。
- 批量移出：启用「设置家庭组」，保持名称为空并保存。
- 列表中显示家庭组徽标，点击可筛选成员；筛选器支持全部、未加入和各家庭组，并显示可见成员数。
- 改名可先筛选旧家庭组，再对全部匹配账号批量设置新名称。最后一个成员移出后，旧名称自动从选项消失。

## 数据与接口

- 使用现有 `accounts.extra.family_group` 字符串，无需数据库迁移。
- 名称去除首尾空白，最长 100 个 Unicode 字符，大小写敏感；不允许控制字符或保留值 `__unset__`。
- 缺少字段表示此次不修改；空字符串或 null 表示移出。普通编辑、凭据更新保留未提交的家庭组。
- `GET /api/v1/admin/accounts/family-groups` 返回 `{ name, account_count }[]`，只聚合未删除且调用者可见的账号。
- 账号列表、轻量列表、自动刷新、倍率刷新、按条件批量编辑和导出接收 `family_group`；`__unset__` 筛选未加入的账号。
- 过滤在数据库 COUNT 和分页前执行，保持总数、跨页选择和导出一致。观察员沿用其账号分组可见范围。
