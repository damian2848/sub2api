# Fork 源码基线与保留改动

本 fork 自 2026-10-11 起以 `ranxi2001/sub2api` 的完整 `production` 源码为基线。当前固定提交为 `7393d736e`（production 与 v2.12.0 一致，2026-10-16 发布；包含上游 v0.2.17 适配及后续兼容修复）；旧主线基线为 `345458a70`（v0.2.45）。保留双方提交历史，但源码不继续混用旧 fork 的网关、调度、Prism 或监控实现。

## 保留范围

- 账号模型白名单的批量连通性测试：每批最多 3 个请求，支持取消、逐模型结果，成功不清除账号已有错误或限流状态。
- 模型白名单支持一键清除当前连通性测试失败的模型，保留可用、未测试及仅智商测试未通过的模型；测试进行中禁用清除，保存账号后生效。
- 白名单糖果智商测试：与连通性测试分开，严格校验答案、显示实际回答，保留 Bedrock、Antigravity 和多协议题目透传。原有智商测试使用上游的模型选择与测试流程，并保留手动/定时测试的 xhigh 选项及能力查询失败兜底。
- 账号管理分组列：完整显示全部分组，长名称自动换行，取消标签截断、数量折叠和两行裁剪。
- 可用渠道页：按平台与分组展示独立模型列表，结合分组白名单、账号模型能力与 OpenAI OAuth 模型目录过滤展示，隐藏空分组。
- 打票全流程：实际转发时记录门票使用事件，包含使用账号、来源账号、自采/借票、网关、协议和业务/管理员测试类型；历史保留最近 200 条，不记录票据或 Cookie。
- 支付充值页：保留支付宝/微信 Stripe 二维码内嵌、金额与订单状态展示、取消/过期处理、异步加载和离页清理。订单、回调、余额与支付接口使用二开库原版。

其余业务运行代码、配置、数据库迁移和依赖采用二开基线，包括网关借票、Mihomo、BPS、平台支持及监控。后续同步优先更新二开基线，再按以上范围重放本地改动，不恢复旧 fork 的无关实现。

## 数据与发布边界

新源码与旧主线共有的 328 个迁移文件内容一致；新增 5 个二开迁移。迁移执行器按完整文件名检查历史校验和，旧 fork 的 7 个专属迁移不再随源码发布；源码切换不删除数据库中的历史记录或旧表。

旧 fork 的托管 Prism 账号、专属监控设置等不能视为与二开实现兼容，生产切换前需在数据库副本上验证，并按二开部署方式检查运行配置。此次源码切换不代表已经执行生产升级。

本地仓库的 `fork` 远端仍指向 `damian2848/sub2api`，`origin` 指向 `ranxi2001/sub2api`。推送、发版和部署应显式指定目标。本 fork 当前源码版本为 `2.12.0`，更新器指向 `damian2848/sub2api`，避免自动更新覆盖保留的定制。发布流程沿用二开工作流，并遵守本仓库 `PUBLISH_CONTAINER_IMAGES=false` 设置，只发布程序与重新登录运行包。上述发布身份与工作流适配不改变二开业务功能。
