# Fork 源码基线与保留改动

本 fork 自 2026-10-11 起以 `ranxi2001/sub2api` 的完整 `production` 源码为基线。当前固定提交为 `f76fd80a9`（v2.10.6，2026-10-12 同步）；旧主线基线为 `345458a70`（v0.2.45）。保留双方提交历史，但源码不继续混用旧 fork 的网关、调度、Prism 或监控实现。

## 保留范围

- 账号模型白名单的批量连通性测试：每批最多 3 个请求，支持取消、逐模型结果，成功不清除账号已有错误或限流状态。
- 白名单糖果智商测试：与连通性测试分开，严格校验答案、显示实际回答，保留 Bedrock、Antigravity 和多协议题目透传。原有智商测试使用上游的模型选择与测试流程，并保留手动/定时测试的 xhigh 选项及能力查询失败兜底。
- 账号管理分组列：完整显示全部分组，长名称自动换行，取消标签截断、数量折叠和两行裁剪。
- 可用渠道页：按平台与分组展示独立模型列表，结合分组白名单、账号模型能力与 OpenAI OAuth 模型目录过滤展示，隐藏空分组。
- 支付充值页：保留支付宝/微信 Stripe 二维码内嵌、金额与订单状态展示、取消/过期处理、异步加载和离页清理。订单、回调、余额与支付接口使用二开库原版。

其余业务运行代码、配置、数据库迁移和依赖采用二开基线，包括网关借票、Mihomo、BPS、平台支持及监控。后续同步优先更新二开基线，再按以上范围重放本地改动，不恢复旧 fork 的无关实现。

## 数据与发布边界

新源码与旧主线共有的 328 个迁移文件内容一致；新增 5 个二开迁移。迁移执行器按完整文件名检查历史校验和，旧 fork 的 7 个专属迁移不再随源码发布；源码切换不删除数据库中的历史记录或旧表。
